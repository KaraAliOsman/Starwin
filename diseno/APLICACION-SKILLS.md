# Decisiones aplicadas desde las skills

Instalación verificable en `SKILLS-INSTALADAS.json`: ocho nuevas skills de Anthropic, Vercel e Impeccable; Emil Design Engineering, Apple Design y Mobile Native ya existían. El registro fija repositorios, commits disponibles y hashes de SKILL.md. No se afirma que instalar una skill certifique el resultado.

| Before | After | Why |
| --- | --- | --- |
| Varias capas acumuladas de CSS y cambios de paleta | Un archivo base reescrito, un archivo propio de portada, logo original y cian/oro documentados | Frontend Design e Impeccable: tomar una decisión visual coherente y mantenerla |
| Una fachada prestada con título superpuesto | Imagen luminosa del archivo Starwin con espacio y detalle seleccionables | Evidencia Starwin/BauFens: escala, integridad material y roles fotográficos distintos |
| Presentación de herramientas mezclada con la venta | Contacto en la primera pantalla móvil; herramientas en navegación secundaria | Apple/Emil: jerarquía para la tarea del visitante |
| Entradas animadas genéricas | Una transición de vista de 180ms, cancelable y respetuosa de reduced motion | Emil/Apple: respuesta a una acción, sin ocultar contenido |
| Apariencia evaluada por métricas | Capturas en cinco anchos, pruebas funcionales y revisión visual independiente por separado | Mobile Native/Webapp Testing: el render real importa; una puntuación no demuestra calidad estética |

React Best Practices y Composition Patterns quedan disponibles para futuras ampliaciones de las herramientas. No se introdujo React en la portada para justificar su instalación. Canvas Design no se utilizó: esta entrega es una web semántica, no un lienzo rasterizado.
